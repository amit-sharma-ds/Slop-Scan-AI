# SlopScan AI Pro

Premium Next.js dashboard for scanning public GitHub pull requests and scoring low-signal AI review noise.

## Run

```bash
npm.cmd install
npm.cmd run dev
```

Open `http://localhost:3000`.

## Features

- Next.js app router project structure
- Top tabs and left command sidebar
- Real public GitHub PR metadata, comments, and commits fetch
- Local heuristic scoring engine
- Flagged comments, AI intelligence brief, radar chart, detection mix, and activity feed
- Demo fallback when GitHub API is blocked or rate limited
